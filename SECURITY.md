# Security and sensitive reports

This beta runs as an EdgeTX Lua widget. It reads telemetry, renders a dashboard and briefly exchanges CRSF device-info messages. It does not intentionally write model or RF settings, execute downloaded code, or send data over an internet connection.

If private vulnerability reporting is enabled on GitHub, use the repository's Security page to report a security-sensitive issue. Otherwise, open an issue containing only a high-level description and request a private reporting route. Do not publicly post credentials, binding phrases, personal radio backups or details that expose another person's private information.

Only the current beta is maintained at this stage. There is no guaranteed security-response timeline. CPU-limit and ordinary rendering/telemetry faults should normally use the bug-report form, with any private information removed.
